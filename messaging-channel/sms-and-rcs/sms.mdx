Use SMS to extend your agent to text messaging. PolyAI 2-Way SMS uses the same agent brain as voice and web chat, so customers get consistent answers and end-to-end resolution over text, with persistent memory that travels with them across channels.

## What is PolyAI's SMS offering?

We deliver the same industry-leading AI agents to drive natural conversations across multiple channels.

- PolyAI agents understand customer needs over SMS, pull from your systems, and resolve inquiries without human intervention.
- When a conversation needs a person, the agent hands off seamlessly with full context.
- Three modes from one platform: Inbound 2-way, Outbound 2-way, and Triggered 1-way.
- Standards-aligned compliance built in: STOP/START/HELP keywords, opt-in/opt-out enforcement, and rate limiting.

## How PolyAI SMS is different

### One brain

One configuration powers voice, web chat, SMS, WhatsApp, mobile, and email.

### Agent memory

Persistent agent memory that travels with the customer across channels and time.

### Self-service resolution

Complete customer requests end-to-end across channels, not just provide information.

### Built for enterprise

Enterprise security and compliance readiness. STOP/START/HELP, rate limiting, and abuse protection are built in.
