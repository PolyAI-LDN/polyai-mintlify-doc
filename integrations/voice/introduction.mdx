PolyAI integrates with voice platforms for call routing, SIP data exchange, and live-agent handoffs. Connect telephony from **Integrations** > **Telephony** in Agent Studio: click **Add number** and choose how calls should reach your agent.

<Note>
If an option shows **Coming soon**, contact your PolyAI account manager. A project can have one connected telephony integration, such as a Twilio account or a contact center platform, alongside any number of SIP trunks.
</Note>

## Transfer or buy a number

| Option | What it does |
|--------|-------------|
| **[Configure SIP trunk](/integrations/voice/sip/custom-sip)** | Connect any SIP-capable platform, including ones without a dedicated guide |
| **[Forward your existing number](/integrations/voice/pstn-forwarding)** | Forward calls from a number you already have to a new PolyAI number |
| **[Buy Twilio number](/integrations/voice/twilio)** | PolyAI buys and manages a number for you |
| **[Connect Twilio account](/integrations/voice/twilio)** | Use numbers you already own in your Twilio account |

## Contact center platforms

Each of these has a guided setup in Agent Studio that walks you through the steps on both the PolyAI side and the platform side.

| Platform | Key features |
|----------|-------------|
| **[Amazon Connect](/integrations/voice/amazon-connect/amazon-connect)** | Instance ARN, PolyAI CloudFormation stack, contact flows |
| **[Dialpad](/integrations/voice/dialpad)** | Cloud contact center, call management |
| **[Five9](/integrations/voice/sip/five9)** | SIP trunk, call data headers, Handoff API |
| **[Genesys](/integrations/voice/sip/genesys)** | BYOC Cloud trunks, custom SIP headers |
| **[NICE CXone](/integrations/voice/sip/NICECXone)** | Trunk requested from NICE, pseudo-number routing, Signal API handoffs |
| **[Zendesk Talk](/integrations/zendesk)** | Inbound routing and live-agent handoff over SIP |
| **[Zoom](/integrations/voice/zoom)** | Zoom Phone and Contact Center, PolyAI app from the Zoom App Marketplace |

## Managed services

| Option | What it does |
|--------|-------------|
