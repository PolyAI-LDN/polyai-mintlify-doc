Vocode's architecture is a cascaded pipeline: separate transcriber, agent (LLM), and synthesizer classes chained together, not a single speech-to-speech client the way LiveKit's and Pipecat's OpenAI Realtime plugins are. There's no realtime plugin in Vocode to redirect at Raven, so the "point an existing integration's `base_url` at us" pattern used in the [LiveKit](/realtime/guides/livekit) and [Pipecat](/realtime/guides/pipecat) guides doesn't have anything to attach to here.

The door isn't fully closed, though. Vocode's LLM stage in that cascaded pipeline can be pointed at PolyAI's own [Chat API](/api-reference/chat/introduction) instead, as the agent step between Vocode's transcriber and synthesizer. That's a materially different integration, cascaded rather than realtime, and it's documented under the Chat API's own docs rather than here.

<Note>
This page gets filled in properly if a speech-to-speech Vocode integration exists to document. For now, it's a pointer rather than a guide.
</Note>
