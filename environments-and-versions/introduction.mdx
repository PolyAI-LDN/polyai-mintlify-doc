Every project has a **Live** version, the agent actually talking to your customers. You never edit Live directly. Instead you make your changes in an isolated copy of your agent (a Branch) and publish them onto Live when ready. Each publish creates a new version in Live's history, and you can roll Live back to any previous version.

Branches live in [Sandbox](/environments-and-versions/environments), the environment where you build and test in the app. An optional [Staging](/environments-and-versions/staging) environment holds one Branch at a time, so you can test it on your channels before you publish.

## Deployment modes

Choose how you want to manage changes under **Deployment settings**, and change mode as your team grows. Click each mode to learn how it works.

| **Mode** | **How it works** | **Best for** |
|---|---|---|
| [**Simple**](/environments-and-versions/simple-mode) | No Branches. You edit your agent's working copy and publish it onto Live when ready. | A single builder making straightforward changes. |
| [**Branches**](/environments-and-versions/branches-mode) | Everyone works in their own Branch, tests it, and publishes onto Live when ready, so nobody blocks anyone else. Optional Staging environment for testing through real channels. No Sub-branches. | Small teams working in parallel, each publishing their own isolated changes. |
| [**Sub-branches**](/environments-and-versions/sub-branches-mode) | The full model. A team splits one Branch into Sub-branches, merges them back, tests together, and publishes as one. Optional Staging environment for testing through real channels. | Several people building updates that ship as one package. |

Every mode keeps the same foundations: publishing merges onto Live, each publish creates a version in Live's history, and you can roll Live back to any previous version. A lighter mode simply removes layers. Switching to a lighter mode never deletes existing work; it only stops you creating the layer it removes.

## Terminology

| **Term** | **Description** |
|---|---|
| [**Environment**](/environments-and-versions/environments) | Where a version of your agent runs. Every project has three. |
| [**Sandbox**](/environments-and-versions/environments#sandbox) | The environment where you build and test. Every Branch and Sub-branch lives here. |
| [**Staging**](/environments-and-versions/staging) | An optional environment for testing one Branch on your channels. |
| [**Live**](/environments-and-versions/environments#live) | The environment serving your customers. You never edit it directly. Publishing merges changes onto it, and each publish creates a new version in its history. You can roll back to any previous Live version. |
| [**Branch**](/environments-and-versions/branches-mode) | An isolated copy of your agent, branched off Live. Publishing merges it back onto Live. |
| [**Sub-branch**](/environments-and-versions/sub-branches-mode) | An isolated copy of your agent, branched from a Branch. It only ever merges back into its parent Branch. |
| [**Out of sync**](/environments-and-versions/branches-mode#handle-an-out-of-sync-branch) | Your working copy is behind its parent. Pull the parent's changes in before publishing or merging. |
