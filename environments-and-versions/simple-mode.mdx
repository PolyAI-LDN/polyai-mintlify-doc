Simple mode is for a single builder making straightforward changes. There are no Branches: you edit your agent's working copy in the Sandbox environment, review and test it, and publish it onto Live when ready.

<img className="hidden dark:block" src="/images/deployment/deployment-simple-mode-dark.svg" alt="Simple mode: a working copy in Sandbox publishes onto Live" style={{ maxWidth: '920px', width: '100%', margin: '0 auto' }} />

## How it works

Your working copy lives in the Sandbox environment, which has no API or telephony connections, so nothing you build can reach a real system. It saves as you go, and you can test it at any time by running [simulation tests](/testing/simulation-tests) or by talking to your agent over an in-app call or chat. When ready, publish: your changes merge onto Live and become the newest version in Live's history. If anything goes wrong, roll Live back to any previous version.

## Make a change

<Steps>
  <Step title="Make your change">
    It saves as you go.
  </Step>
  <Step title="Test it">
    Run [simulation tests](/testing/simulation-tests), or talk to the agent yourself over an in-app call or chat.
  </Step>
  <Step title="Publish">
    Your changes merge onto Live and become the newest version in Live's history.
  </Step>
</Steps>

## Comparing with Live

You can compare your working copy with Live side by side to confirm only your intended change is present. See [Compare branches](/environments-and-versions/diffs).

## Roll back Live

<Steps>
  <Step title="Open Live's version history">
    Every publish is a version there.
  </Step>
  <Step title="Select a previous version and roll back">
    Live returns to that version in one step.
  </Step>
</Steps>

<Tip>
Because publishing merges rather than replaces, a rollback cannot be silently undone by someone else's publish.
</Tip>

Outgrowing Simple mode? Switch to [Branches](/environments-and-versions/branches-mode) or [Sub-branches](/environments-and-versions/sub-branches-mode) under **Deployment settings**. Switching never deletes existing work.
