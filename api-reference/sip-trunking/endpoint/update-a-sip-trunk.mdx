Omitted fields are left unchanged.

## Default route

`inbound.default_route` sets, replaces or clears the agent that receives calls to numbers with no extension on the trunk. See [Default route](/api-reference/sip-trunking/introduction#default-route).

| To      | Send                                                              |
| ------- | ----------------------------------------------------------------- |
| Set     | `{"inbound": {"default_route": {"agent": {"agent_id": "my-agent", "client_env": "live"}}}}` |
| Replace | The same, with a different `agent`                                |
| Clear   | `{"inbound": {"default_route": {"disable": true}}}`               |

Provide exactly one of `agent` or `disable: true`; anything else returns `400`. Omitting `default_route` leaves it unchanged.
