---
title: "Get conversation timeline"
api: "GET /api/v1/traces/conversations/{conversation_id}/timeline"
description: "One row per turn and span name, with start, end, duration and error count, in order."
---

Collapses a conversation's spans into a chronological timeline: for each turn and span name, when the first such span started, when the last one ended, and how many failed. Lighter than [fetching every span](/api-reference/traces/endpoint/get-conversation-trace) when you want a per-turn latency picture.

## Request

### Headers

<ParamField header="X-API-KEY" type="string" required>
  Account API key with read access to conversations.
</ParamField>

### Path parameters

<ParamField path="conversation_id" type="string" required>
  The conversation to summarise.
</ParamField>

### Query parameters

<ParamField query="project_id" type="string">
  The agent the conversation belongs to. Optional with an account API key.
</ParamField>

## Response

<ResponseField name="conversation_id" type="string" />
<ResponseField name="project_id" type="string" />
<ResponseField name="total" type="integer">
  Number of entries.
</ResponseField>
<ResponseField name="entries" type="object[]">
  Ordered by `turn_index`, then `start_time`.

  <Expandable title="properties">
    <ResponseField name="turn_index" type="integer">
      `null` for spans outside a turn.
    </ResponseField>
    <ResponseField name="span_name" type="string" />
    <ResponseField name="start_time" type="datetime">
      Earliest start among the group's spans, UTC.
    </ResponseField>
    <ResponseField name="end_time" type="datetime">
      Latest end among the group's spans, UTC.
    </ResponseField>
    <ResponseField name="duration_ns" type="integer" />
    <ResponseField name="duration_ms" type="number" />
    <ResponseField name="error_count" type="integer">
      Spans in the group with status `Error`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Meaning |
| ------ | ------- |
| `401`  | Missing or invalid API key. |
| `403`  | The key cannot read conversations. |
| `404`  | The conversation has no spans, or belongs to another account. |
| `502`  | The trace backend did not answer. |
