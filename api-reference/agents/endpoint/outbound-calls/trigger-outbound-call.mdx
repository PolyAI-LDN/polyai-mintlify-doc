<Note>
This endpoint places calls over PolyAI-managed telephony. If you've connected your own telephony platform as a [SIP Trunk](/api-reference/sip-trunking/introduction), place outbound calls over it with [Place an outbound call](/api-reference/sip-trunking/endpoint/place-an-outbound-call) instead.
</Note>
