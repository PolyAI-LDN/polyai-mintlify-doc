---
title: "List metrics"
openapi: "GET /api/v1/metrics"
---

<Note>
Call this first. The `name` values it returns are the only metric names [Aggregate a metric](/api-reference/data/endpoint/metrics/aggregate-a-metric) and the `filters` on [Search conversations](/api-reference/data/endpoint/conversations/search-conversations) accept. Built-in metrics such as `poly_score` are listed alongside the custom metrics your projects define.
</Note>
