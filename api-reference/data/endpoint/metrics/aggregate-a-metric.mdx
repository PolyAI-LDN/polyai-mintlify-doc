---
title: "Aggregate a metric"
openapi: "POST /api/v1/metrics/aggregate"
---

<Warning>
**Experimental.** This endpoint is tagged experimental by the service: the request and response shape may change without a version bump. Pin your client to the fields you use and check this page before relying on new ones.
</Warning>

The response is tabular. `columns` names the values in each row, in order: `bucket` when `interval` is set, then one column per `group_by` dimension, then one column per requested aggregation. Rows are sorted by bucket ascending, then by `sort` if you set one.

For a worked example that ends with weekly Poly Score by channel, see [Read Poly Score from the CLI and the API](/api-reference/data/read-poly-score).
