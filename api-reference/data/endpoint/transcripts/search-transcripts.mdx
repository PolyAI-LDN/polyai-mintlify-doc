---
title: "Search transcripts"
openapi: "GET /api/v1/transcripts/search"
---

<Note>
Transcript text is PII. This endpoint requires the **PII read** permission on your API key and returns `403` without it. Personal Access Tokens must also pass `project_id`.
</Note>

Each result is one conversation with the turns that matched `q`. Every matched turn carries `context.before` and `context.after`, up to `context_turns` on each side. `english_user_input` and `english_agent_response` are set for non-English conversations.
