---
title: "Get a transcript"
openapi: "GET /api/v1/transcripts/conversation/{conversation_id}"
---

<Note>
Transcript text is PII. This endpoint requires the **PII read** permission on your API key and returns `403` without it.
</Note>

Returns every turn of one conversation in order. Find conversation IDs with [Search conversations](/api-reference/data/endpoint/conversations/search-conversations) or [Search transcripts](/api-reference/data/endpoint/transcripts/search-transcripts).
